# 20TO100K.IQ Trade Engine

نظام ملفّي خفيف لتحديث الصفقات دون إعادة بناء الموقع.

## المجلدات
- `inbox/` صور الصفقات الجديدة
- `processed/` صور الصفقات التي تمت معالجتها
- `rejected/` صور غير صالحة أو ناقصة
- `templates/` مخطط الصفقة
- `social/` نصوص Instagram / TikTok / Telegram الجاهزة للنشر
- `TRADE_UPDATE.txt` قالب التحديث البشري

## مصدر الحقيقة الرسمي
`data/trades.json`

الموقع العام قراءة فقط. لا يستطيع الزائر تعديل السجل الرسمي من المتصفح.

## ملاحظة مهمة
هذه النسخة تجهز وتوحّد البيانات والنصوص، لكنها لا تنشر تلقائيًا إلى Instagram أو TikTok أو Telegram. النشر الآلي يحتاج Backend + مفاتيح/صلاحيات رسمية محفوظة كـ Secrets، وليس داخل GitHub.
